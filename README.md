## 二、从 0 到 1 原创剧集全流程八阶段把控体系

1. **第一阶段（立项定调与导演表达）**：通过 `20% 高概念强钩子外壳 × 40% 强现实烟火肌理 × 40% 反套路普世哲学核` 三维融合公式确立项目定位，撰写深入回答“为什么拍、讲什么核心生命体验”的导演阐述，并锚定亲情、友情、爱情三大受众情绪出口。
2. **第二阶段（世界观与底层规则）**：构建时代与社会空间基底，确立 8—10 条具备明确触发条件与代价限制的底层运行法则。
3. **第三阶段（全局故事架构与节奏“度”的把控）**：按“每3集一局部高潮、每8集一核心矛盾升维”规划全剧长度容量；严控喜悲呼吸度（先喜后悲、悲中带喜）与三本时间账（A客观顺时序/B呈现序/C角色认知差）；单集45分钟严格执行五幕心电图节拍（前3分钟冷开场立钩＋最后2分钟强断章尾钩）。
4. **第四阶段（草蛇灰线与长线伏笔工程）**：所有大结局引爆的破局钥匙，均按“前1/3集数日常伪装无痕初埋 ➔ 中段唤醒与状态变奏 ➔ 大结局最高潮颠覆回收”三步工程法提前规划。
5. **第五阶段（一人一档立体人物设计）**：单个人物独立一档（不设合集总集、不标演员名字、无末尾凑数表），完整涵盖：核心设定总卡、从头到脚全身骨相与跨时期穿搭视觉硬锁、表里反差心理画像、全剧完整生平事件长篇传记、关系拓扑网与代表性经典台词。
6. **第六阶段（一景一档空间美学与动线）**：单个场景独立一档（不设合集总集、无末尾凑数表），完整涵盖：工程美学参数卡、外立面至内部陈设全景细描、子空间拓扑与多视角机位动线、跨时期色温光影演变与全剧核心事件纪实。
7. **第七阶段（专业文学剧本 8 道断言）**：严格执行零表格、零导读框、零`△`、零`〔〕`、零镜头号与演员名、场次匹配、角色居中加粗＋台词缩进无引号、以及“一句对白＋一段微动作”交替律（`max_consec == 1`）；每集片尾统一为左顶格加粗 `*开始片尾音乐：` ＋ 右对齐加粗 `切至黑屏，片尾`。
8. **第八阶段（横向6列导演分镜与六维五表解码）**：将文学剧本无缝转化为 11×8.5 英寸横向宽幅 6 列专业导演分镜脚本与单集六维五表深度解码。
